## 시간복잡도 감각 (1초 ≈ 1억 연산)
| 복잡도 | 허용 n |
|---|---|
| O(log n) | 사실상 무제한 (10¹⁸도 약 60번) |
| O(n log n) | 약 10⁶ 안전 |
| O(n²) | 약 10⁴ |
| O(n³) | 약 500 (Python은 200 내외) |

- 이진탐색은 O(log n). n log n은 "정렬 + 탐색" 또는 "n번 탐색"일 때

## 서로소 집합 (Union-Find)
```python
parent = list(range(n + 1))

def find(x):  # 반복문 버전: 재귀 제한 걱정 없음
    root = x
    while parent[root] != root:
        root = parent[root]
    while parent[x] != root:
        parent[x], x = root, parent[x]
    return root

def union(a, b):
    a, b = find(a), find(b)
    if a < b: parent[b] = a
    else: parent[a] = b
```
- 루트 비교는 `parent[a]`가 아니라 반드시 `find(a)`
- 재귀 버전이면 `sys.setrecursionlimit(10**6)` 필수

## 크루스칼 (MST)
- 간선을 `(cost, a, b)`로 저장 → 정렬 → `find(a) != find(b)`면 union + 비용 합산
- O(E log E). 응용: MST에서 가장 비싼 간선 빼면 "두 마을 분할"

## 플로이드 워셜 (모든 쌍 최단거리)
5단계 틀: INF 초기화 → 자기 자신 0 → 간선 입력 → 3중 for → 출력
```python
for k in range(1, n + 1):          # k가 반드시 가장 바깥
    for a in range(1, n + 1):
        for b in range(1, n + 1):
            graph[a][b] = min(graph[a][b], graph[a][k] + graph[k][b])
```
- 노드 n 기준 O(n³) → n ≤ 100 안전, 400~500은 Python 위험
- 변형은 주로 간선 입력과 출력만 바뀜
  - 양방향: `graph[a][b]`, `graph[b][a]` 두 줄 / 단방향: 한 줄
  - 중복 간선: `graph[a][b] = min(graph[a][b], c)`
- 함정: 경유 변수 `k`가 문제 입력 `k`와 겹치면 덮어써짐 (미래도시)
- 자기 자신 0 안 하면 대각선에 "한 바퀴 도는 비용"이 들어가서 틀림

## 다익스트라 (한 출발점 → 모든 노드)
```python
import heapq
def dijkstra(start):
    q = [(0, start)]
    distance[start] = 0
    while q:
        dist, now = heapq.heappop(q)
        if distance[now] < dist:   # 빼먹으면 시간 초과
            continue
        for nxt, cost in graph[now]:
            d = dist + cost
            if d < distance[nxt]:
                distance[nxt] = d
                heapq.heappush(q, (d, nxt))
```
- 그래프는 인접 리스트 `graph[u].append((v, w))`
- 힙 버전 O(E log V) / 선형 탐색 버전 O(V²)
- 중복 간선은 별도 처리 불필요 (알아서 짧은 쪽으로 갱신)
- 플로이드 대안: 모든 쌍이 필요하면 노드마다 다익스트라

## DP 유형별 점화식
- 인접 선택 불가: `dp[i] = max(dp[i-1], dp[i-2] + a[i])`
- 연속합: `dp[i] = max(dp[i-1] + a[i], a[i])`
- 동전 최소 개수: `dp[i] = min(dp[i], dp[i-coin] + 1)` / 경우의 수: `dp[i] += dp[i-coin]`
- 0-1 배낭: `dp[w] = max(dp[w], dp[w-weight] + value)` (무게 역순 루프)
- LIS: `a[j] < a[i]`면 `dp[i] = max(dp[i], dp[j] + 1)`
- LCS: 같으면 `dp[i-1][j-1] + 1`, 다르면 `max(dp[i-1][j], dp[i][j-1])`
- 접근: dp[i] 의미 정의 → 마지막 선택으로 경우 나누기 → 초기값

## Python 문법 메모
- `[i for i in range(n) if 조건]`: 컴프리헨션의 if는 필터
- `list(range(n + 1))` == `[i for i in range(n + 1)]`
- `print(*row)`: 리스트를 공백 구분 한 줄 출력
- `nxt`: 내장함수 `next`와 충돌 피하려는 관례
- 입력 많으면 `input = sys.stdin.readline`
