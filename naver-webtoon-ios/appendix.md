# 부록. 면접 스토리 & 15개월 로드맵

[← 목차](00-overview.md)

## A. 버딩크 트러블슈팅 → 면접 스토리 카드

| 사례 | 연결 이론 | 답변 구조 (문제 → 원인 → 해결 → 배운 점) |
|---|---|---|
| 세로 영상 렌더링 버그 | AVFoundation, KVO, 레이아웃 사이클 | 세로 영상이 잘못 표시 → presentationSize가 재생 준비 후 확정 → KVO로 관찰해 레이아웃 갱신 → 비동기 상태 확정 시점의 중요성 |
| Swift Concurrency context 이슈 | actor 격리, `@MainActor`, Swift 6.2 변화 | 컨텍스트 오류 발생 → 격리 규칙 위반 지점 파악 → 격리 명시로 해결 → 지금이라면 `@concurrent` 등 명시적 오프로딩 |
| 트레이너 재설치 트랩 | 상태 코드, 멱등성, 로컬 상태 신뢰성 | 재설치 후 진행 불가 → 로컬 플래그와 서버 상태 불일치 → "이미 등록됨"을 성공으로 처리 → 서버를 단일 진실 공급원으로 |
| FCM 캠페인 미수신 | SDK 내부 동작, 설정 디버깅 | 타깃팅 푸시 미수신 → AppDelegate 프록시 비활성 설정이 Analytics 연동 차단 → 설정 조정 → 서드파티 SDK 동작 원리 확인 습관 |
| SPM 한글 경로 · gRPC C++20 빌드 에러 | 빌드 시스템, 의존성 관리 | 패키지 해석 실패 → 경로 인코딩 문제 → 경로 변경 → 재현 가능한 빌드 환경의 중요성 |

| ~2027.06 | 3장 UIKit 원리, 4장 반응형·SwiftUI + 코테 Lv.2 | 뷰어 설계 메모(6장 예습) |
| ~2027.09 | 5장 아키텍처·테스트, 6장 뷰어·미디어·결제, 9장 패턴·FP·Storyboard | 연습 지원 3~5곳, 면접 회고 |
| ~2027.12 | 7장 성능·보안, 8장 CS 정리, 9장 ePub·다국어·Obj-C 보강, 코테 Lv.2 안정화 | 이력서 최종본, 테스트 코드·다국어·Obj-C 데모 |

## D. 공식 학습 소스

- Swift 공식 문서: The Swift Programming Language (docs.swift.org). ARC, Concurrency 챕터
- Apple Developer Documentation: UIKit, AVFoundation, StoreKit
- WWDC 세션 (developer.apple.com/videos). 각 챕터 검색 키워드의 세션명
- Swift Forums, Swift Evolution(SE 제안서). 언어 변화 근거 확인

> 공고·전형 정보는 2025~2026년 공개 공고와 후기 기준이며 변경될 수 있습니다. Swift/Xcode 버전별 동작은 공식 문서로 최종 확인하세요.
